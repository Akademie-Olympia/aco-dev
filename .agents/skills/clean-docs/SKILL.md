# clean-docs
- Language English; headings short; one idea per paragraph; examples runnable.
- Per repo README: purpose, install, configuration, dependencies, link to aco-docs.
- Behaviour change => docs change in the same commit.
- Cross-repo facts live in `aco-dev/docs/`; keep STRUCTURE.md in sync when repos, paths or flows change.
- Remove outdated text instead of appending "note: ...".
